Planificacion territorial

Configura provincias y seccionales del exterior.

Cada provincia guarda metas editables para celdas municipales o distritales, nombre de coordinadores y meta total de activistas. El mapa usa estos objetivos para calcular el semaforo territorial.

Las seccionales del exterior trabajan con una directiva seccional de 20 activistas mas 20 adicionales por cada circunscripcion activa.

En esta vista, el responsable provincial dirige la provincia, el supervisor regional acompaña varias provincias y el enlace macroregional articula toda la macroregion.

Las macroregiones ahora se organizan como paneles desplegables para que puedas abrir solo la estructura que quieres revisar.
